En esta version de la prueba se implementa el consumo de la api OpenWeather para poder obtener la informacion del clima de una region que el usuario busque

Al inicio cargara la informacion del clima de su ubicacion actual en caso de que otorgue los permisos de esta

Se cuenta con un buscador que, mediante GooglePlaces ayuda a buscar lugares en especifico de Mexico para buscar su informacion del clima

En la parte inferior se muestra un mapa el cual navega hacia la ubicacion seleccionada en el buscador


Aun implementare la opcion de el funcionamiento de manera offline, la conversion de modelos entre capas, ya que aun estoy usando el mismo modelo de la respuesta y la seccion de los Tests.



El apk para instalar y probar la aplicacion se encuentra en la seccion de Releases, de igual manera adjunto el link para poderla descargar: https://github.com/carlosttorres33/WeatherAppPositivo/releases/download/V1/WeatherApp1.0.0.apk
